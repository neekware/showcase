# @repo/agx-store

**A simple flat state/store that helps implementing lite-redux patterns**

# Overview

## Description

This library helps implementing a flat `redux` state store, with simplicity and performance in mind.

**@repo/agx-store** attempts to simplify the reactive implementation of your browser application, through minimal `redux` patterns, while promoting DRY **DRY**.

# How to install

```bash
  // add this to your package.json
  "@repo/agx-store": "workspace:*"
```
